Part 107 Remote ID Practice Test

Remote ID is the newest material on the knowledge test, and it trips up pilots who studied from older prep books. All 10 Remote ID questions, with answers and references

The drill above shuffles the answer choices on every attempt. Below is the same 10-question set written out in full, in a fixed order, so you can read it straight through, print it, or check a single rule without restarting a quiz. Each answer carries the reasoning and the FAA source it rests on.

  1. What are the three ways to comply with the Remote ID rule?

    • A. A Standard Remote ID drone, a broadcast module, or flying at a FRIA Correct answer
    • B. Registration, insurance, and a waiver
    • C. A transponder, ADS-B Out, and radar contact
    • D. Filing a flight plan before each mission

    Why: Compliance paths: built-in Standard Remote ID, an add-on broadcast module, or flying without RID only inside an FAA-Recognized Identification Area.

    Reference: 14 CFR Part 89

  2. A drone using a Remote ID broadcast MODULE (instead of built-in Standard RID) must be operated:

    • A. Only in Class G uncontrolled airspace below 400 ft
    • B. Within visual line of sight at all times Correct answer
    • C. Only below 200 ft AGL
    • D. Only during daylight

    Why: Module-equipped aircraft must stay within VLOS — one of the two key module limitations, along with registering the module's serial number.

    Reference: 14 CFR Part 89

  3. What must be done with a broadcast module's serial number?

    • A. Keep it strictly confidential for national security reasons
    • B. Etch it on the propellers
    • C. List it in the aircraft's FAA registration record Correct answer
    • D. Nothing — it activates automatically

    Why: The module serial number must be entered into the registration (FAA DroneZone) of each aircraft it flies on.

    Reference: 14 CFR Part 89; FAA DroneZone guidance

  4. A FRIA is best described as:

    • A. A paid FAA fast-track authorization zone
    • B. An FAA-recognized area where drones may fly without any Remote ID equipment Correct answer
    • C. Any private property with the owner's permission
    • D. A frequency reserved for drone telemetry

    Why: FAA-Recognized Identification Areas — typically requested by community organizations and schools — are the only places non-RID aircraft may fly, within their boundaries and VLOS.

    Reference: 14 CFR Part 89

  5. Which data set does a Standard Remote ID drone broadcast?

    • A. The pilot's name and home address
    • B. The remote pilot certificate number
    • C. The aircraft's complete maintenance history
    • D. Drone ID, drone location/altitude and velocity, control station location/altitude, time mark, and emergency status Correct answer

    Why: Standard RID includes the CONTROL STATION location — one reason the FAA adopted it for security. It does not broadcast your name; the public sees only the ID string.

    Reference: 14 CFR Part 89

  6. Remote ID applies to which aircraft?

    • A. Only drones over 55 lb
    • B. All drones required to be registered — including every aircraft flown under Part 107 Correct answer
    • C. Only recreational drones
    • D. Only drones flying beyond visual line of sight

    Why: If registration is required, Remote ID applies. Part 107 aircraft must ALWAYS be registered regardless of weight, so they always need RID (or a FRIA).

    Reference: 14 CFR Part 89, Part 48

  7. Since when has operator compliance with Remote ID been required?

    • A. September 16, 2023 Correct answer
    • B. January 1, 2020
    • C. It is voluntary until 2030
    • D. Only after the next FAA rulemaking cycle

    Why: Operators have been required to comply since September 16, 2023 (the FAA's enforcement discretion period ended March 16, 2024).

    Reference: 14 CFR Part 89

  8. How can you verify that your drone has Standard Remote ID?

    • A. Ask the retailer
    • B. Check whether the aircraft weighs over 250 g
    • C. Look it up on the FAA's public Declaration of Compliance (DOC) list Correct answer
    • D. Assume that any drone manufactured after January 2020 complies automatically

    Why: The FAA's DOC database lists compliant makes/models; most current mainstream drones comply via firmware, but verification is the pilot's responsibility.

    Reference: FAA UAS Declaration of Compliance listing

  9. An FAA-Recognized Identification Area (FRIA) allows:

    • A. any Part 107 operation to be flown without registering the aircraft at all
    • B. broadcast Remote ID to be switched off anywhere within 5 NM of the site
    • C. night operations without anti-collision lighting, provided the site itself is lit
    • D. aircraft without Remote ID to fly within visual line of sight of the site Correct answer

    Why: A FRIA is a defined geographic area where an aircraft with no Remote ID capability may be flown, as long as it stays within visual line of sight of the person operating it and inside the area. Registration and every other Part 107 rule still apply.

    Reference: 14 CFR 89.115(b); Part 89 subpart D

  10. A remote pilot fits a broadcast module to an older aircraft that has no built-in Remote ID. That operation must then be flown:

    • A. only at night, when the module's transmissions are least likely to be masked
    • B. only after the module serial number is added to the original manufacturer declaration
    • C. only in Class G airspace below 400 ft AGL and clear of any controlled airspace
    • D. within visual line of sight at all times Correct answer

    Why: A broadcast module carries a stricter condition than Standard Remote ID: the aircraft must remain within visual line of sight for the whole flight, so no line-of-sight waiver can be used with one. The module's serial number goes in the aircraft's FAA registration record, not the manufacturer's declaration.

    Reference: 14 CFR 89.110, 89.115
